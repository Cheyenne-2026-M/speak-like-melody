# 英文跟讀練習 MVP

流程：看句子 → 播放老師錄音 → 學生錄音 → 播放學生錄音 → 自行比較差異。

## 使用方式

1. 把老師的錄音檔（mp3）放進 `audio/` 資料夾，檔名需跟 `sentences.json` 裡的 `audio` 欄位對應（目前預設是 `sentence1.mp3`、`sentence2.mp3`、`sentence3.mp3`）。
2. 編輯 `sentences.json`，增減句子（`text` 是要練習的句子，`audio` 是對應老師錄音檔的相對路徑）。
3. 瀏覽器要求 getUserMedia（錄音權限）必須在「安全環境」下才能用，直接雙擊打開 `index.html`（file://）會抓不到麥克風，所以要先啟動一個本機伺服器：

   ```bash
   cd ~/english-speaking-practice
   python3 -m http.server 8000
   ```

4. 瀏覽器打開 `http://localhost:8000`，第一次錄音時瀏覽器會跳出麥克風權限請求，按允許即可。

## 目前這版做了什麼 / 沒做什麼

做了：
- 逐句瀏覽（上一句/下一句）
- 播放老師錄音
- 錄學生自己的聲音、播放回聽
- 純前端、無後端、無資料庫，方便先驗證流程

沒做（之後可以再加）：
- 學生錄音沒有被儲存下來（換頁或關掉分頁就消失）
- 沒有發音評分或波形比對，純粹靠學生自己聽
- 沒有帳號系統、沒有進度紀錄
